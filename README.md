# Kazevo Adventure Launch

Project Goal: Build a high-converting, mobile-responsive landing page for a vibrant outdoor brand called kazevo.

Design Aesthetic:

Use a "Dopamine" aesthetic: high-energy, vibrant color-contrast (Electric Purple, Sunset Orange, Mint Green).

Modern, clean, and airy UI using Tailwind CSS.

Bold sans-serif typography (e.g., Inter or Montserrat).

Geometric color-blocking and smooth transitions.

Page Structure:

Hero Section: A large headline "kazevo: 190g of Pure Adventure" with a subheadline about ultra-lightweight performance. Include a primary "Shop Now" CTA button.

Feature Grid: A 3-column grid highlighting:

"Ultra-Lightweight" (190g feather-light design).

"Ergonomic Comfort" (Arc-shaped shoulder straps).

"Durable Nylon" (Weather-resistant premium material).

Product Showcase: A section showing the color variants (Deep Green, Deep Purple, Vibrant Orange, Light Green, Classic Black) with interactive color swatches.

Technical Specs Table: A clean, minimalist table showing the product attributes (Material, Weight, Capacity, etc.).

Lifestyle Gallery: A section for high-energy hiking imagery.

Footer: Simple navigation links and social icons.

Technical Requirements:

Fully responsive (mobile-first).

Use Lucide-react for icons.

Ensure high performance and fast loading.

Use a sticky navigation bar with the kazevo logo. the attached pictures are the products i sell
